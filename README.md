# SDLC Planning, Analysis, and Design: Track Logistics System

## Overview
This project covers the **Planning**, **Analysis**, and **Design** phases of the Systems Development Life Cycle (SDLC) for a **Track Logistics System**. It focuses on structuring workflows, system requirements, data flows, and architectural design to support reliable shipment tracking and delivery operations.

## Key Highlights & GRC Relevance
* **Requirements & Security Controls:** Defined functional and non-functional requirements, including data/credential encryption, availability, scalability, and usability.
* **System & Data Architecture:** Modeled system interactions and data movement using **Use Case Diagrams**, **Context & Level 0 DFDs**, an **ERD**, and a **3-Tier Client-Server Architecture** (Presentation, Business Logic, and Data tiers).
* **Operational Governance & Visibility:** Designed role-based flows for clients, delivery drivers, and system managers along with operational monitoring and reporting.

## Deliverables Included
* SDLC methodology selection (Agile) and project schedule (Gantt chart)
* Functional and non-functional requirements specification
* Use Case Diagram, Context DFD, Level 0 DFD, and ERD
* 3-Tier Architecture, UI flow/screens, and UML Class Diagram
